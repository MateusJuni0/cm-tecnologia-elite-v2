# PROJECT: CMTecnologia Elite V2

## Vision
Transform the existing vanilla HTML/JS website into a high-performance, SEO-optimized, premium digital presence using modern technologies (Next.js, TypeScript, Tailwind, Framer Motion).

## Primary Goals
- **Elite Performance:** 95+ Lighthouse scores.
- **Superior UX:** Remove intrusive alerts, implement imersive feedback (Toasts).
- **International SEO:** Proper i18n routing (/pt, /en).
- **Scalable Architecture:** Modular Design System in Next.js.
- **Conversion focus:** Clarity in CTAs and Value Proposition.

## Core Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Validation:** Zod + React Hook Form
- **i18n:** next-intl
